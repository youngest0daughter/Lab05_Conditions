### Блок кода
Пример реализации функции получения подсказки с использованием современного паттерн-матчинга в операторе `switch`:

```csharp
string GetHint(int difference) {
     switch (difference) {
         case <= 3:
             return "Горячо!";
         case <= 10:
             return "Тепло";
         case <= 25:
             return "Прохладно";
         default:
             return "Холодно";
     }
}
```

### Итоговая таблица

| Конструкция | Когда использовать |
| :--- | :--- |
| `if/else` | Общее ветвление, сложные составные условия |
| `else if` | Несколько последовательных взаимоисключающих вариантов |
| `switch/case` | Сравнение одной переменной с конкретными значениями или паттернами |
| Тернарный оператор `? :` | Выбор одного из двух значений в одну строку для краткости |
| `&&` | Логическое И — оба условия должны быть истинны (`true`) |
| `||` | Логическое ИЛИ — хотя бы одно условие должно быть истинно (`true`) |
| `!` | Логическое НЕ — отрицание/инверсия логического значения |
| `int.TryParse()` | Безопасное преобразование строки в число без вызова исключений |
| `Random.Next(min, max)` | Генерация случайного числа в заданном полуоткрытом диапазоне |

### Ответы на вопросы

1. `int.Parse()` при получении некорректной строки вызывает критическую ошибку и аварийно останавливает программу. Метод `int.TryParse()` в таком случае просто вернет `false` и запишет в переменную `0`, не ломая программу. `int.Parse()` стоит использовать только тогда, когда мы на 100% уверены в корректности формата данных. Во всех случаях пользовательского ввода с консоли следует использовать `int.TryParse()`.

2. `switch` удобнее, когда одна конкретная переменная проверяется на равенство списку фиксированных значений. Это делает код более плоским и читаемым. Пример из жизни — выбор пункта меню на терминале самообслуживания или реакция на нажатие определенной клавиши в игре (W, A, S, D).

3. В C# компилятор выдаст ошибку сборки, так как «сквозное» выполнение (fall-through) между непустыми блоками case запрещено.

4. Один знак `=` — это оператор присваивания. Два знака `==` — это оператор сравнения. Их часто путают по привычке из математики, пытаясь выполнить сравнение через один знак `=`, что приводит к синтаксическим ошибкам.

5. Да, это называется вложенным тернарным оператором. Пример из лабораторной: 
     `string weather = temp >= 20 ? "тепло" : (temp >= 0 ? "прохладно" : "мороз");`
     Читаемость такого кода значительно ниже, чем у классического `if/else`. Его легко запутать при аудите кода, поэтому вложенные тернарные операторы рекомендуется избегать.
